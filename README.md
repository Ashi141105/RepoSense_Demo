# RepoSense_Demo

A lightweight file storage and task processing API with user authentication and file uploads.

## Components
- `app.py`: Main application routing and request handling.
- `auth.py`: User session token creation and verification.
- `upload.py`: File upload processing, size validation, and disk persistence.
- `config.py`: Global configuration and environment settings.
- `utils.py`: Helper functions for cryptographic hashing and file formatting.

## Running the Application
```bash
python app.py
```
